# qlnoise —— 光学量子线路的噪声分析（线路层）

把物理噪声参数（损耗、模式失配、分束比失衡、相位偏置）喂进精确的 Fock 空间
演化，输出可比较的指标：符合概率、输出分布、分布重叠度、成功概率，以及一张
**误差预算表**——告诉你预算有限时先修哪个。

> 不做的部分：源的多对发射、探测器暗计数、纠错阈值、全波传播。
> 这里只到「线路层」。

---

## 跑起来

```bash
pip install -r qlnoise/requirements.txt

python qlnoise/analyze.py             # 生成 qlnoise/report/report.md + 4 张图
python qlnoise/analyze.py -o out      # 指定输出目录
```

默认输出固定到 `qlnoise/report/`，在哪个目录下运行都一样；`-o` 给了相对路径才
按当前目录。只依赖 numpy + matplotlib。

报告里的**每个数字都是现算的**，没有手填。跑完先看第 3 节自检表：两行偏差应该
都在 1e-15 量级。**如果不为零，后面的结论都不要信。**

当前实测（2026-11-03，Windows / Python 3.12.8 / numpy 2.4.4）：

```
HOM 自检最大偏差：1.67e-16
MZI 自检最大偏差：2.22e-16
```

from qlnoise import NoiseParams, hom, mzi, two_stage

## 三个线路

| 线路 | 理想行为 | 噪声签章 |
|---|---|---|
| **HOM** | 符合计数为 0（两个光子总从同一侧出） | 任何噪声都把 0 抬起来 |
| **MZI** | 单光子，$P_0=\sin^2(\phi/2)$ | 相位误差→条纹平移；失衡→变浅；损耗→整体压低 |
| **两级网络** | 第一级干涉 + 第二级再干涉 | 同样的 V 过第二级再掉一些（见下方说明） |

HOM 的特殊之处：**它的理想值是 0，所以符合概率本身就是噪声计**，不需要另做
层析。损耗的影响是乘性的，符合概率按 $\eta^2$ 缩小。

> **关于第三个线路**：原本打算做后选择 CNOT，但 CNOT 的标准分解要走 NS 门的
> 三分束器网络，那组反射率参数没有经过验证。所以本轮先用两级干涉网络占位，
> CNOT 等能跑真值表的时候再上。
>
> 另外，报告 §6 目前用 45° 相位扫可见度，这个工作点上 V 的影响只有二阶的：
> V = 0.90 时分布重叠度仍有 0.9997，和「噪声会累积」的标题对不上。90° 下
> V = 0.90 会掉到 0.975。这一节待重做（改扫相位或改工作点），结论暂不引用。

## 噪声模型

| 噪声 | 实现 | 说明 |
|---|---|---|
| 透过率 η | 与真空端口做 BS，再投影辅助模回真空 | 精确等于振幅阻尼，保相位 |
| 模式可见度 V | $\rho = V\rho_\text{ind} + (1-V)\rho_\text{dis}$ | 对符合概率严格；对保真度是标准近似 |
| 分束比失衡 δ | 反射率 $0.5+\delta$ 进 BS 矩阵 | 酉矩阵偏离 |
| 相位偏置 δφ | 相移器偏置 | 条纹平移 |

**关键区别**：损耗是乘性的——它抬高的符合概率按 $\eta^2$ 缩小，掉的主要是
成功率而不是条件保真度；模式失配是一阶的，直接破坏干涉。把两者揉成一个
depolarizing 参数，会同时高估损耗对保真度的破坏、低估它对计数率的破坏。

## 度量

- `distribution_fidelity(d1, d2)`：输出分布的重叠（Bhattacharyya 系数），不是
  Uhlmann 保真度。线路层的噪声最后都落在「测出来是什么」上，分布层面的度量更
  贴近实验能验证的量。
- `tvd(d1, d2)`：总变差距离。
- `postselect(dist, predicate)`：按条件筛选输出，返回条件分布和成功概率。
- `excess_coincidence(p, p_ideal)`：符合概率超出理想值的部分，直接当噪声计。
- `Mixture.fidelity_pure(psi)`：需要态层面保真度时用这个。

## 误差预算

`analysis.error_budget()` 把每个噪声源**单独**恶化到典型实验室水平，其余保持
完美，同时看两列：

| 噪声源 | 典型值 | 符合概率增量 | 双光子探测率变化 |
|---|---|---|---|
| 模式可见度 V | 0.97 | +0.01500 | 0.0000 |
| 分束器反射率 R | 0.505 | +0.00010 | 0.0000 |
| 透过率 η | 0.95 | 0.00000 | −0.0975 |
| 相移器偏置 δφ | 0.5° | 0.00000 | 0.0000 |

两列排序不同：保真度侧第一是 V，计数率侧第一是 η。用单一指标做预算会漏掉
一半的物理。

## 已知局限

- 可见度用经典混合插值，忽略部分可分辨态里的相干项；对符合概率严格，对多光子
  线路的保真度是近似。
- 没有建模源的多对发射和探测器暗计数（属于光源/探测层）。
- 没有做到纠错层，给不出「这个损耗水平能不能容错」的结论。
- 第三个线路是两级干涉网络，**不是 CNOT**。
- 报告 §5 表的「偏离理想值」把相位偏置算进了参考相位（`ideal_p0` 用的是
  `phase_deg + phase_error_deg`），所以这一列实际只反映损耗和分束比失衡；
  相位偏置的效果要看图里的条纹平移。

## 再往前一步

1. **后选择 CNOT**：把 NS 门分解参数用真值表锁死。
2. **源与探测**：多对发射、暗计数、抖动接进来。
3. **纠错阈值**：擦除通道和去极化通道的阈值差两个数量级，值得单独做一层。
